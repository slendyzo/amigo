Design language

The token system it lives in

Amigo's shell is driven entirely by CSS custom properties — one warm neutral scale plus a single amber accent, with green/red/sky/violet reserved for meaning (money, loss, assets, projects). Everything below renders live in the current theme; use the toggle to check both.

Heads-up for the brief: the docs still call this a "Shadcn Electric Blue theme," but the live shell tokens override to amber (warm gold in dark). Radius is generous (0.75rem base, iOS-ish), motion runs on cubic-bezier(.16,1,.3,1) long eases, type is Inter/system. Treat amber as the identity to evolve.

Information architecture

Five destinations, three of them hubs

The primary nav is a flat 5-item rail (desktop sidebar, collapsible to icons). Money, Portfolio and Settings are hubs — their sub-pages light the parent up. Insights appears only when AI is enabled; Inbox only for the admin account. On mobile this becomes a 4-tab bottom bar with a center add-button and a "More" drawer.

Before you redesign

What the brief needs to respect

Constraints and quirks that will bite a redesign if missed — pulled from the live code, not the docs.

Amber is the identity

Single accent, #d97706 light / #fbbf24 dark. Semantic green/red/sky/violet are not accents — they mean money, loss, RWA, projects. Keep that separation.

Both themes are first-class

Dark isn't an invert — it has its own warmer-gold accent and near-black ground. Design and check both; the toggle top-right proves this page does.

Mobile-first PWA

Bottom-tab + center-add + right drawer is the primary surface, offline-capable (IndexedDB). Desktop sidebar is the adaptation. 44px touch targets.

Motion has a house curve

Long eases on cubic-bezier(.16,1,.3,1), 300–500ms, staggered reveals, animated tab underlines. Wrapped/Retrospective are the flourish moments.

Data-dense, scan-first

This is a tool, not a doc — summary before detail, state encoded as chips/pills/severity, tabular-nums for aligned figures. Charts get area fills + faint grids.

AI is sunset

Insights + nudges + AI-consent exist but generation is off. Don't design new AI-dependent flows; the Advisor toggle is now just a consent switch.
