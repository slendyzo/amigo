Design principles

  • - Amount is king - 48px hero input at the top
  • - Currency below amount (tap to change)
  • - Name input clean, single field
  • - All options in iOS Settings-style grouped rows
  • - Each row shows current value on the right
  • - Chevron indicates tappable/expandable
  • - Tags as horizontal pills below rows (always visible)
  • - Single CTA button at bottom

Layout

Header (Cancel/Title) → Hero Amount → Name → Grouped Rows → Tags → CTA
