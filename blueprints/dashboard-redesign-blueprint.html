Philosophy

Your money app is a ledger. Open it, see what you spent. Budget bar tells you if you're over. Everything else — charts, breakdowns, trends — lives in a separate Insights page you visit weekly, not daily. First transaction visible at ~155px.

Primary question: "Am I on track?"

Budget health is the hero — a big visual at the top that instantly tells you green/amber/red. Category bars show where money goes. Transactions below, but the budget story comes first. Think YNAB meets Apple Health rings.

How it works

The hero card has two states, toggled by the button at the bottom:

Collapsed (default): Ring gauge + spent/budget + income/balance. Transactions start at ~230px. You see your budget health + recent transactions at a glance.

Expanded: Card grows to reveal type breakdown (Contas fix/var, Gastos, Projetos), category stacked bar, and a mini burn chart. Same content as the desktop sidebar, just stacked vertically. Transactions push down but are still scrollable below. Tap "Ocultar detalhes" to collapse back.

The expand/collapse state persists (localStorage) so if you like seeing the details, it stays open.

Pulse — Desktop

Two-column layout. Left = transactions (always visible). Right = sticky sidebar with budget health, category breakdown, burn chart, and the type split. All current info accounted for.

C — The Cockpit

Primary question: "Give me everything at once."

Dense information design. Budget, spending breakdown, AND recent transactions all visible without scrolling. Compact rows, smaller type, zero wasted space. You open the app and the entire financial picture is right there. Think Bloomberg terminal energy, but clean.

Philosophy

Your money app is a command center. Dark header = numbers. Category bars = spending shape. Light section = transaction detail. Everything visible on first load — budget, income, balance, category breakdown, AND 5+ transactions. No scrolling needed for a complete picture. First transaction at ~210px. Comparison

A — Ledger B — Pulse C — Cockpit
Answers "What did I spend?" "Am I on track?" "Show me everything"
1st transaction at ~155px ~400px ~210px
Budget visibility Thin bar in sticky header — always visible but minimal Hero ring gauge — impossible to miss Numbers + bar in dark header — prominent but compact
Category breakdown None (separate Insights page) Stacked bar + legend — prominent Horizontal mini-bars with proportional height
Stats (income/balance/etc) Horizontal scroll chips Beside the ring gauge 3x2 grid in dark header
Visual personality Clean, light, airy — banking app Warm, visual — health dashboard Dense, dark/light split — power tool
Transaction rows Day-grouped cards, standard size, with category Flat list, compact, relative dates ("Hoje", "Ontem") Day-grouped, tight rows, minimal info per row
Month navigation Sticky header arrows + swipe Top arrows (scrolls away) + swipe Compact arrows in dark header
Best for Daily check-ins, quick logging Budget-conscious users, monthly review Data nerds, glanceable overview
