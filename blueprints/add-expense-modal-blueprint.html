Add Expense Modal Redesign

3 variants to reduce clutter and improve the mobile flow

Current pain points: Too many visible fields at once (name, amount, split, date, tags, type, category, bank account, photos, exclude toggle). The modal feels like a form, not a quick-add.

Option A: "Hero Amount" with Smart Rows

Amount front-and-center. All other options are tappable rows with inline values. Feels like Apple Wallet / Revolut.

Key Design Decisions

  • + Giant amount = the most important field gets the spotlight
  • + Settings-style rows keep everything visible but compact
  • + Each row taps to expand inline (no nested modals)
  • + Tags as horizontal pills at the bottom, always scannable
  • + Split is just another row, not a whole section
  • − Requires inline expansion logic for each row
  • − Expense type selector hidden (needs "more" option)

Inspiration

Apple Wallet transaction details, Revolut payment flow, iOS Settings rows

Option B: "Two-Zone" (Essential + More)

Top zone: only what you need 90% of the time. Bottom zone: everything else behind a single "More options" expand. No scrolling for quick adds.

Key Design Decisions

  • + Quick-add flow: name + amount + tap Add. Zero scrolling.
  • + Quick action tiles show current values at a glance (date, category, account, split)
  • + "More options" hides everything you rarely change
  • + Tags always visible since they're used frequently
  • + Dashed divider visually separates "quick" from "detailed"
  • − Quick action tiles need tap-to-expand sub-modals or inline pickers
  • − Two "modes" may feel inconsistent

Inspiration

Splitwise add expense, Notion quick-create, Linear issue creator

Option C: "Stacked Cards"

Each concern is a self-contained card. Cards that aren't relevant stay collapsed to a single line. Active cards expand. Clean visual hierarchy.

Key Design Decisions

  • + Each card is a self-contained concern with its own visual weight
  • + Active features (split) get colored cards that stand out
  • + Collapsed "Details" card shows values as tiny badges - visible but not noisy
  • + Receipt is a single collapsed line until you need it
  • + Amount + name + date live together as one "essential" card
  • + Tags always visible (used frequently enough)
  • − Cards add vertical space with borders/padding
  • − Might still need scrolling when split + details both expanded

Inspiration

Wise transfer flow, Apple Card transactions, Monzo payment details
